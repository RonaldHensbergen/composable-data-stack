# Kubernetes MVP — Gate Checklist and Sign-off (G0.0–G5.5)

Version: 0.2
Status: Draft — companion checklist to [k8s-haven-mvp.md](k8s-haven-mvp.md), updated 2026-11-07 (Gate 4.5 added).

This is the executable form of the runbook: one row per task (G0.0–G5.5), with
the exact instructions, a one-line explanation of *why*, the exit criterion,
the effort estimate, and a sign-off column to fill in while running. The
runbook (`k8s-haven-mvp.md`, sections 5–10) remains the source of truth for
context; this file is the working checklist.

## How to use

- Run everything from the fresh directory (Path A, `~/cds-mvp`) unless a row
  says **clone (Path B)**. Record which path each task used.
- Secrets only through `cds init` / `.env` (mode 0600, untracked). Nothing
  secret-shaped goes into this checklist, the evidence bundle, or issues.
- Every task is sized ≤ 2 h. If one runs over, split it under its tracking
  issue — do not silently grow it.
- A gate never signs off over an open blocking issue (runbook section 2).
- Tick the [ ] in a row's sign-off cell only when its exit criterion is met, then
  complete the cell: result (pass/fail/blocked), initials, date, evidence link.
  The gate-level table is at the bottom.

Sign-off cell format per row: `☑ pass/fail/blocked · initials · YYYY-MM-DD · evidence link`

## Gate-level sign-off

A gate is signed off only when all its rows above are signed off, its exit
criteria (runbook sections 5–10) are met, every blocking issue assigned to it
(runbook section 2) is closed, and every remaining non-blocking gap is filed as
an issue.
